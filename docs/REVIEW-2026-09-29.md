# Five-seat review, 2026-09-29

Scope: the initial commit `3ebd767` (612 lines). Seats: Staff, Product, Design, Network,
Security. Each finding was debated against the code before being accepted; declined
candidates are listed with the evidence that cleared them so they are visible as decisions,
not omissions. Every accepted fix has a locking test written red-first where the defect was
testable; the two layout fixes were proven to discriminate by stashing the fix and watching
exactly those tests fail.

## Declined, with evidence

| Seat | Candidate | Why declined |
|---|---|---|
| Security | Add CORS headers | Wrong direction: the absence of CORS is what keeps cross-origin pages from reading the API. Adding any `Access-Control-Allow-Origin` would weaken S1. |
| Security | Add an auth token | Anything local can already read `/proc` or run `ps`; a token adds a copy-paste step and no security. The real remote vector (rebinding) is closed by S1. |
| Security | Vendor Three.js instead of CDN | Correct in principle (removes the third-party origin and the internet requirement). Declined for now: +~700 KB in a 600-line repo, and SRI + version pin already fixes the code-substitution risk. Revisit if the toy grows. |
| Network | Request timeouts / slowloris | Loopback only; the only client is your own browser. `daemon_threads=True` so Ctrl-C exits cleanly regardless. |
| Network | ETag / 304 on `/api/snapshot` | The snapshot changes every interval by construction (`t` and CPU), so a conditional GET would never hit. ~80 KB every 2 s on loopback is not a cost. |
| Staff | Replace `ThreadingHTTPServer` with an async framework | Adds a dependency to a stdlib-only server for no user-visible gain at one client. |
| Staff | Cache `Process` objects manually for `cpu_percent` deltas | `psutil.process_iter` already caches `Process` instances internally, so `cpu_percent(interval=None)` deltas are correct across calls (psutil docs, verified by the non-zero CPU readings in the live run). |
| Design | Colour-blind palette for users | Colour is per-user and arbitrary; the tooltip and top panel carry the same information as text. Emissive glow is luminance, not hue, so it survives colour-vision deficiency. |
| Product | Persist camera position across reloads | The camera auto-centres on the city centroid; persistence adds `localStorage` state for a toy. |
